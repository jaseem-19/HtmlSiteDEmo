Paragraph Alignments

Left This paragraph is aligned to the left, which is the default alignment for most text content on the web.

Right This paragraph is right-aligned, often used for dates or signatures.

Center This paragraph is centered, commonly used for headings and titles.

Justify This paragraph is justified. The text stretches so that each line has equal width, creating a clean block appearance similar to newspapers and books.

Technology Definitions

A definition list of key web technologies.

HTML

HyperText Markup Language — the standard language for creating web pages and web applications.

CSS

Cascading Style Sheets — used to describe the presentation and layout of HTML documents.

JavaScript

A high-level, interpreted programming language that enables interactive web pages and dynamic content.

React

A JavaScript library for building user interfaces, maintained by Meta and a community of developers.

Node.js

A runtime environment that executes JavaScript code outside a web browser, enabling server-side development.
